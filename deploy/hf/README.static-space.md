# Safqa صفقة — live demo

Static demo of [Safqa](https://github.com/Omar08263/safqa), a price and deal tracker for Noon Egypt and Amazon Egypt.

- Demo login: `demo@safqa.app` / `demo1234` (prefilled on the login page)
- The data is a snapshot recorded from a real, seeded Safqa API. The API runs in your browser
  (`apps/web/src/lib/demo-api.ts`), so login, watchlist, and alerts are saved only in your browser.
- Built by `deploy/hf/deploy-static.sh` in the GitHub repo.
